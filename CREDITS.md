# Asset credits and licensing

## Original work, created for this site

Nothing here is traced from, or based on, any existing character, franchise or artwork.

| Asset | How it was made |
|---|---|
| `images/art/character.svg` | Original character, hand-written as SVG code |
| `images/art/character-figure.webp`, `character-wind.webp` | Rasterised from `character.svg` (figure and wind layer) |
| `images/art/foreground.svg` | Original power-line silhouette, hand-written SVG |
| `images/art/project-ai.svg`, `project-shooter.svg`, `project-tasks.svg` | Original project illustrations, generated from code. They contain no real product screenshots or figures |
| `images/art/scene-*.webp` | Rendered from this site's own Three.js scene, for the 2D fallback |
| `images/favicon.svg` | Original icon |
| `images/og-card.jpg` | Screenshot of this site's hero, used for social sharing |
| Everything in `js/3d/world/` | Procedural geometry and shaders. No 3D models or textures are downloaded |
| Katakana on neon signs | Drawn from hand-defined strokes in `js/3d/world/signs.js`, so no font is needed |

`images/Keshavprashar.jpeg` is Keshav Prashar's own portrait, carried over from the original site.
